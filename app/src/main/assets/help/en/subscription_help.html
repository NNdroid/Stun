A subscription is just an HTTPS address. Stun fetches the node list from it and imports, updates or removes nodes on this device automatically.

1. The address

  • Only https:// is accepted. Plain http, ftp and sftp are rejected — subscription content decides which servers you connect to, so an unencrypted channel would let anyone rewrite it.
  • The same address is stored only once. Adding it again updates the existing entry instead of creating a duplicate.

2. Supported file formats

Stun tries the following in order and stops at the first one that yields nodes. Mixed content is not supported.

2.1 One stun:// node per line

The most common format — the same text you get from “Share as text” for a single node, one per line. The whole file shares one PIN.

stun://eyJ2IjoxLCJnIjoi…
stun://eyJ2IjoxLCJnIjoi…
Note: as soon as the file contains any line starting with stun:// or stun:, Stun uses only this format. Every other line is ignored — including a plain JSON array sitting next to it.

2.2 A plain JSON array

An array of Stun node objects. Every entry must carry a non-empty sshAddr or proxyAddr; entries without either are skipped.

[
  { "id": "node-1", "name": "Tokyo", "sshAddr": "…", "proxyAddr": "…" },
  { "id": "node-2", "name": "Osaka", "sshAddr": "…", "proxyAddr": "…" }
]

2.3 The whole file, PIN-encrypted

The body is one encrypted envelope ({"v":1,…}) produced by Stun. Enter the PIN on the subscription row, otherwise the import stops and says so.

2.4 Base64 of the JSON array

Exactly the text from 2.2, Base64-encoded. Whitespace and line breaks inside the Base64 are ignored.

3. Optional metadata

Real HTTP response headers win. Whatever they leave out may be declared inside the file; whatever is still missing keeps its previous value, so a response that omits a header once will not wipe the subscription name or homepage button.

content-dispositionname
The name shown in the subscription list. Chinese and other non-ASCII names work via the RFC 5987 form. A trailing file extension is dropped, so “Airport.yaml” shows as “Airport”. 
# content-disposition: filename*=UTF-8''Airport
# content-disposition: filename="Airport.yaml"
profile-web-page-urlhomepage
Adds a “Homepage” button on the subscription row. Only http/https values are used. 
# profile-web-page-url: https://example.com
profile-update-intervalinterval
How often, in whole hours, this subscription is refreshed in the background. Without it Stun falls back to 24 hours. 
# profile-update-interval: 12
subscription-userinfotraffic
Feeds the traffic card: used / total, upload, download and expiry. All values are bytes; expire is a Unix timestamp in seconds. Partial values are fine — a missing total simply means “unlimited”. 
# subscription-userinfo: upload=123; download=456; total=1000; expire=1790000000

Declaration syntax inside the file

  • A line whose first non-blank character is #, followed by name: value. Spaces between # and the name are allowed, and names are case-insensitive.
  • If a name appears more than once, the first one wins. An empty value counts as “not declared”.
  • Any other # line is treated as a comment and dropped — so # Airport is safe to write.

4. How a sync changes your node list

  • Merge by id. A node whose id already exists is updated in place; a new id is added.
  • Removal. Nodes that belong to this subscription but are absent from the latest response are treated as taken down and deleted.
  • Two exemptions. Favourited nodes and the currently selected node are never deleted by a sync.
  • No accidental wipe. Removal only runs after at least one node was parsed successfully. A network hiccup or an empty response fails the sync instead of emptying the subscription.
  • Cross-subscription deduplication. The same node id appearing in several subscriptions is imported once.

5. PIN

  • An encrypted subscription needs its PIN before anything can be imported.
  • Wrong or missing PINs are reported as such instead of failing silently.
  • The PIN is stored per subscription. After changing it, sync the subscription again.

6. Background updates

  • The “Background auto-sync” switch in this panel is the master switch.
  • Each subscription is refreshed when its own profile-update-interval has elapsed (24 hours if it declares none).
  • Stun re-checks every 15 minutes and only while a network is available — it does not poll the server on a fixed 15-minute cadence.

7. What the error messages mean

  • Enter a valid HTTPS subscription URL — the address is not https:// or has no host.
  • The server returned an error — the response status was outside 200–299.
  • Network request failed — connection, timeout or TLS problem.
  • No valid nodes in the subscription — the payload was fetched but no branch could parse a node out of it.
  • This subscription is PIN-encrypted. Enter the PIN. / Wrong PIN or decryption failed — see section 5.
