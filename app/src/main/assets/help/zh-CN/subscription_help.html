订阅就是一个 HTTPS 地址。Stun 从它拉取节点列表，并自动在本机导入、更新或移除节点。

1. 地址要求

  • 只接受 https://。明文 http、ftp、sftp 一律拒绝 —— 订阅内容决定你用哪台服务器，明文通道会被中间人整套改写。
  • 同一个地址只保留一条订阅。重复添加是更新已有那条，不会产生重复项。

2. 支持的文件格式

Stun 按下面的顺序尝试，命中一种就停止。不支持多种格式混写。

2.1 每行一个 stun:// 节点

最常见的一种 —— 就是单节点「以文本分享」出来的那段内容，一行一个。整份文件共用一个 PIN。

stun://eyJ2IjoxLCJnIjoi…
stun://eyJ2IjoxLCJnIjoi…
注意：只要正文里出现以 stun:// 或 stun: 开头的行，Stun 就只按这一种格式解析，其余行（包括旁边那份明文 JSON 数组）全部忽略。

2.2 明文 JSON 数组

Stun 节点对象组成的数组。每一项的 sshAddr 或 proxyAddr 必须非空，两者都为空的项会被跳过。

[
  { "id": "node-1", "name": "东京", "sshAddr": "…", "proxyAddr": "…" },
  { "id": "node-2", "name": "大阪", "sshAddr": "…", "proxyAddr": "…" }
]

2.3 整份文件 PIN 加密

正文是一整个加密信封（{"v":1,…}，由 Stun 生成）。需要在订阅行上填 PIN，否则导入会停下并明确提示。

2.4 JSON 数组的 Base64

把 2.2 的内容整体做 Base64。中间的空白与换行会被忽略。

3. 可选信息

真响应头优先。响应头没给的，可以写在文件里补；两边都没有的项会沿用上次已存的值 —— 所以某次响应少带一个头，不会把订阅名或首页按钮抹掉。

content-disposition名称
订阅在列表里显示的名字。中文等非 ASCII 名字走 RFC 5987 写法即可。末尾的文件扩展名会被去掉，「机场.yaml」就显示成「机场」。 
# content-disposition: filename*=UTF-8''七星机场
# content-disposition: filename="七星机场.yaml"
profile-web-page-url首页
在订阅行上加一个「首页」按钮。只认 http/https。 
# profile-web-page-url: https://example.com
profile-update-interval间隔
这条订阅后台自动更新的间隔，单位是整小时。不声明时按 24 小时算。 
# profile-update-interval: 12
subscription-userinfo流量
喂给流量卡：已用 / 总量、上行、下行、到期时间。数值单位都是字节，expire 是 Unix 秒级时间戳。可以只给一部分 —— 缺 total 就按「不限量」显示。 
# subscription-userinfo: upload=123; download=456; total=1000; expire=1790000000

文件内声明的写法

  • 整行第一个非空字符是 #，后面跟 头名: 值。# 与头名之间可以有空格，头名大小写不敏感。
  • 同一个头名出现多次时以第一条为准；值为空视同没声明。
  • 其他 # 行一律当注释丢掉 —— 所以写 # 七星机场 是安全且推荐的。

4. 一次同步会怎么改你的节点列表

  • 按 id 合并。 id 已存在就原地更新，新 id 则新增。
  • 清理下架节点。 归属本订阅、但本次响应里没有的节点，视为已下架并删除。
  • 两处豁免。 已收藏的节点和当前选中的节点，同步永远不会删。
  • 不会误清空。 只有在成功解析出至少一个节点之后才会执行清理。网络抖动或服务端返回空内容，这次同步会直接失败，而不是把整份订阅清空。
  • 跨订阅去重。 同一个节点 id 出现在多条订阅里时，只会导入一次。

5. PIN

  • 加密订阅必须填对 PIN 才能导入。
  • 没填和填错会分别提示，不会静默失败。
  • PIN 按订阅单独保存。改过 PIN 之后需要重新同步这条订阅。

6. 后台自动更新

  • 面板上的「后台自动同步」是总开关。
  • 每条订阅按自己的 profile-update-interval 到期才更新；没声明的按 24 小时。
  • Stun 每 15 分钟检查一次，且只在有网络时检查 —— 并不是每 15 分钟就去请求一次服务器。

7. 各种报错是什么意思

  • 请输入有效的 HTTPS 订阅链接 —— 地址不是 https://，或没有主机名。
  • 服务器返回错误 —— HTTP 状态码不在 200–299。
  • 网络请求失败 —— 连不上、超时或 TLS 证书问题。
  • 订阅中没有有效节点 —— 内容拉回来了，但没有任何一种格式能解析出节点。
  • 该订阅为 PIN 加密内容，请输入 PIN / PIN 错误或解密失败 —— 见第 5 节。
