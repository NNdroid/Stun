訂閱就是一個 HTTPS 網址。Stun 從它取得節點清單，並自動在本機匯入、更新或移除節點。

1. 網址要求

  • 只接受 https://。明文 http、ftp、sftp 一律拒絕 —— 訂閱內容決定你連哪台伺服器，明文通道會被中間人整份改寫。
  • 同一個網址只保留一筆訂閱。重複加入是更新既有那筆，不會產生重複項目。

2. 支援的檔案格式

Stun 依下列順序嘗試，命中一種就停止。不支援多種格式混寫。

2.1 每行一個 stun:// 節點

最常見的一種 —— 就是單一節點「以文字分享」出來的那段內容，一行一個。整份檔案共用一個 PIN。

stun://eyJ2IjoxLCJnIjoi…
stun://eyJ2IjoxLCJnIjoi…
注意：只要內容出現以 stun:// 或 stun: 開頭的行，Stun 就只用這一種格式解析，其餘的行（包含旁邊那份明文 JSON 陣列）全部忽略。

2.2 明文 JSON 陣列

由 Stun 節點物件組成的陣列。每一項的 sshAddr 或 proxyAddr 必須非空，兩者都為空的項目會被略過。

[
  { "id": "node-1", "name": "東京", "sshAddr": "…", "proxyAddr": "…" },
  { "id": "node-2", "name": "大阪", "sshAddr": "…", "proxyAddr": "…" }
]

2.3 整份檔案 PIN 加密

內容是一整個加密信封（{"v":1,…}，由 Stun 產生）。需要在訂閱列上填 PIN，否則匯入會停下來並明確提示。

2.4 JSON 陣列的 Base64

把 2.2 的內容整份做 Base64。中間的空白與換行會被忽略。

3. 選用資訊

真正的回應標頭優先。回應標頭沒給的，可以寫在檔案裡補；兩邊都沒有的項目會沿用上次已儲存的值 —— 所以某次回應少帶一個標頭，不會把訂閱名稱或首頁按鈕抹掉。

content-disposition名稱
訂閱在清單中顯示的名稱。中文等非 ASCII 名稱用 RFC 5987 寫法即可。結尾的副檔名會被去掉，「機場.yaml」就顯示成「機場」。 
# content-disposition: filename*=UTF-8''七星機場
# content-disposition: filename="七星機場.yaml"
profile-web-page-url首頁
在訂閱列上加一個「首頁」按鈕。只認 http/https。 
# profile-web-page-url: https://example.com
profile-update-interval間隔
這筆訂閱在背景自動更新的間隔，單位是整數小時。沒有宣告時以 24 小時計。 
# profile-update-interval: 12
subscription-userinfo流量
提供給流量卡：已用 / 總量、上行、下行、到期時間。數值單位都是位元組，expire 是 Unix 秒級時間戳。可以只給一部分 —— 缺 total 就顯示為「不限量」。 
# subscription-userinfo: upload=123; download=456; total=1000; expire=1790000000

檔案內宣告的寫法

  • 整行第一個非空白字元是 #，後面接 標頭名: 值。# 與標頭名之間可以有空白，標頭名不分大小寫。
  • 同一個標頭名出現多次時以第一筆為準；值為空視同沒宣告。
  • 其他 # 行一律當成註解丟掉 —— 所以寫 # 七星機場 是安全且建議的。

4. 一次同步會怎麼改你的節點清單

  • 依 id 合併。 id 已存在就原地更新，新 id 則新增。
  • 清掉已下架節點。 屬於這筆訂閱、但這次回應裡沒有的節點，視為已下架並刪除。
  • 兩處豁免。 已加入收藏的節點與目前選取的節點，同步永遠不會刪。
  • 不會誤清空。 只有在成功解析出至少一個節點之後才會執行清理。網路不穩或伺服器回傳空內容，這次同步會直接失敗，而不是把整筆訂閱清空。
  • 跨訂閱去重。 同一個節點 id 出現在多筆訂閱裡時，只會匯入一次。

5. PIN

  • 加密訂閱必須填對 PIN 才能匯入。
  • 沒填與填錯會分別提示，不會靜默失敗。
  • PIN 依訂閱各自儲存。改過 PIN 之後需要重新同步這筆訂閱。

6. 背景自動更新

  • 面板上的「背景自動同步」是總開關。
  • 每筆訂閱依自己的 profile-update-interval 到期才更新；沒宣告的以 24 小時計。
  • Stun 每 15 分鐘檢查一次，且只在有網路時檢查 —— 並不是每 15 分鐘就去請求一次伺服器。

7. 各種錯誤代表什麼

  • 請輸入有效的 HTTPS 訂閱連結 —— 網址不是 https://，或沒有主機名。
  • 伺服器回傳錯誤 —— HTTP 狀態碼不在 200–299。
  • 網路請求失敗 —— 連不上、逾時或 TLS 憑證問題。
  • 訂閱中沒有有效節點 —— 內容取回來了，但沒有任何一種格式能解析出節點。
  • 該訂閱為 PIN 加密內容，請輸入 PIN / PIN 錯誤或解密失敗 —— 見第 5 節。
