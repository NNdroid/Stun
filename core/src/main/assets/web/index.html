🤖 Google Gemini 2.0 Flash / 1.5 Pro 直连 (Python)
利用原生 Function Calling 接口，3 行 Python 直接控制 Stun：
import google.generativeai as genai, requests
tools = requests.get("http://127.0.0.1:37180/gemini/declarations").json()
genai.configure(api_key="YOUR_GEMINI_KEY")
chat = genai.GenerativeModel("gemini-2.0-flash", tools=tools["functionDeclarations"]).start_chat(enable_automatic_function_calling=True)
print(chat.send_message("检查 VPN 状态并测试延迟").text)
